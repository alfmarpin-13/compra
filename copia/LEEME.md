# Copia de seguridad

GitHub guarda aquí cada noche, de forma automática, la **despensa** (`despensa.json`) y las **tiendas** (`tiendas.json`).
No se copian la lista de la compra ni el historial de compras.

Cada copia queda en el historial de cambios del repositorio, así que se puede volver a cualquier día.
Para restaurarlas en Firebase, pídeselo a Claude con estos archivos.
